# Simbotics · REBUILT

FRC 2026 賽季遊戲 **REBUILT** 的 3D 操駕模擬器，純靜態網頁（Three.js），不需要建置步驟，可以直接放上 GitHub Pages。僅供個人使用。

打開網站會先看到首頁，選「比賽模擬器」或「生涯模式」。直接連到 `index.html#sim` 會跳過首頁。

## 功能

- 完整場地：HUB、BUMP、TRENCH、TOWER、DEPOT、OUTPOST、Neutral Zone 的 FUEL
- 比賽流程：0:20 AUTO → 2:20 TELEOP（Transition、Shift 1–4 HUB 輪流啟用、Endgame）
- 計分：FUEL、TOWER（AUTO L1 15 分；結束時 L1/L2/L3 = 10/20/30），以及 Energized / Supercharged / Traversal RP
- 生涯模式（獨立頁面 `career.html`，電腦版）：一整個 2026 賽季。第一人稱 3D 工作室裡設計、採購、親手加工、組裝機器人，再安排交通住宿、打包出發，在完整建模的賽場打真實賽事，一路到休士頓 Einstein（見下方「生涯模式」）
- 賽事模式：資格賽 → 選聯盟 → 雙敗淘汰賽（見下方「賽事模式」）
- AUTO 自動程式：像 PathPlanner 一樣事先畫好 AUTO 路徑與動作（見下方「AUTO 自動程式」）
- 機器人工廠：自己搭配底盤、驅動、intake、hopper、射手、攀爬，組成一台機器人（見下方「機器人工廠」）
- 3v3 對戰（2 台電腦隊友 + 3 台電腦對手）、單人計時、自由練習；隊友與對手可分別設定 AI 難度（簡單／普通／困難／愛因斯坦／傳奇）與戰術
- 2026 真實機器人：254 Overload、1690 Kepler、4946 The Alpha Dogs（圓形底盤）、118 Artemis（雙砲塔）、4414 RIPCURRENT，各自有依照照片還原的 3D 模型與參數；3v3 時可在選單逐台指定隊友與對手開哪台機器人，選「隨機」則從還沒被選的真實機器人中抽
- 另有三台通用機器人：Balanced Swerve、Speedy Shuttle、Heavy Hopper（太高，不能鑽 TRENCH）
- 固定式射手（254）按住射擊會自動轉車頭瞄準（依剎車距離控制角速度，不會左右晃），沿炮管實際方向發射；雙砲塔（118）兩邊輪流射
- 砲塔自動瞄準並補償車速；離開 Alliance Zone 時改成把 FUEL 傳回己方區域
- 三種鏡頭（Driver Station／跟車／轉播），支援鍵盤與手把

### 手機

選單「操作」預設自動偵測，觸控裝置會切到手機模式，直立、橫放都能玩：

- 左半邊螢幕拖曳：移動（搖桿出現在手指按下的位置）
- 右半邊螢幕拖曳：車頭朝向你指的方向
- 自動吸球；自動射擊會在己方區域內、HUB 啟用（或球落地前會啟用）時開火，固定射手會自己轉向 HUB
- 「射擊」按鈕：手動射擊，例如在區域外傳球
- 靠近 TOWER 時出現「攀爬」／「往下」按鈕；右上角有暫停、鏡頭、全螢幕
- 直立時 Driver Station 鏡頭會拉高，轉播鏡頭改成俯視

「自動射擊」也可以在電腦上勾選使用。

### 記錄模式

在選單勾選「記錄模式」，比賽結束時結算畫面會多一個操作記錄框，可以複製或下載成 .txt。內容包含：

- 比賽設定、雙方機器人、最終比分
- 各時段（Auto、Transition、Shift 1–4、Endgame）的進球、射擊、傳球、吸入、平均載球、碰撞時間，以及停留在哪些區域
- 每 0.25 秒一筆的取樣：位置（以己方聯盟為準，兩邊聯盟的記錄可直接比較）、車頭方向、速度、載球、是否射擊／吸球／碰撞、與最近對手和隊友的距離

用途是把自己的打法貼回來，拿來調整電腦 AI。一整場約 670 行（36 KB）。

## 本機執行

ES modules 不能用 `file://` 開，需要一個簡單的伺服器：

```bash
python3 -m http.server 8080
```

然後打開 http://localhost:8080 。

## 部署到 GitHub Pages

1. 把這個資料夾推到一個 GitHub repo（例如 `simbotics`）。
2. Repo → **Settings → Pages** → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`。
3. 等一分鐘左右，網址會是 `https://<你的帳號>.github.io/simbotics/`。

所有路徑都是相對路徑，Three.js 從 jsDelivr CDN 載入（`three@0.160.0`）。

### 生涯模式

網站首頁選「生涯模式」，或直接打開 `career.html`。一整個 2026 賽季：Kickoff（1/10）→ Build Season → 各場賽事 → 地區冠軍賽／休士頓冠軍賽 → Einstein。電腦版限定（鍵盤＋滑鼠）。

- **開始：**
  - 有 3 個存檔欄位。
  - 開場是模擬的 Kickoff 直播：背景跑一場真實比賽，鏡頭巡場、字幕介紹規則，可以跳過。
  - 隊伍可以創立新隊（選所在地），或繼承一支 2026 真實隊伍；強隊有更多預算、機台和有經驗的隊員。
  - 選賽區：區域賽，或 14 個分區之一，再挑真實的 2026 賽事。分區要選 2 場分區賽；也可以像 359、118 一樣多報區域賽，每多一場 $4,000（之後也能在電腦「賽程」加報）。
  - 工作室三選一：
    - **車庫**：小、只有手工具，隨時能用。
    - **學校教室**：有台鑽，放學後和週末白天能用。
    - **贊助商工廠**：大、機台多，平日只有晚上能用。
  - 玩法二選一：
    - **實作模式**：你親手做，只有兩位助手。
    - **管理模式**：隊員多，會自動分工；你也可以隨時自己動手。
- **時間：**
  - 現實 1 秒等於遊戲 1 分鐘，按 1–4 切換 ×1／×2／×4／×8。
  - 用電腦、操作機台時時間照走，Esc 暫停。
  - 到關門時間會結算當天、跳到下次開門，也可以從出入口「收工」。
  - 隊員只在學生時間出現，每天不一定都來，體力會消耗。
- **第一人稱工作室：** WASD 移動、滑鼠看、E 互動。可以互動的東西：
  - 電腦
  - 白板：行事曆和工作看板
  - 工作台
  - 機器人推車
  - 材料架、零件架
  - 門口的包裹
  - 各台機台
  - 隊員
  - 練習場門口
- **電腦：**
  - **專案（BOM）**：設計會拆成約 70 個加工件，加上每個子系統的 COTS。可以：
    - 做細部設計（做完零件才能開工）。
    - 選每個零件的做法：手工、CNC、車床、3D 列印、外包。
    - 把缺的東西一鍵加入購物車。
  - **規則手冊**：遊戲內的簡化版 2026 規則。
  - **CAD**：用機器人工廠的進階模式。改設計時，改到的零件要重做。
  - **瀏覽器**：零件商網站，名稱都是虛構的：AndyMart、Pacific Parts Co.、Swivel Drive Supply、RIV Robotics、CTRx Electronics。另外有機具城 MakerMart（機台和耗材）和 QuickCut 代工。下單後要等運送天數，包裹會放在門口，要自己拆。
  - **信箱**：導師的建議、新隊補助、贊助提案（可接受或婉拒）、耗材用完的通知。
  - **程式**：替 CAN 裝置編號，調整 swerve 轉向和飛輪的控制參數（即時看響應曲線），然後寫程式。編號和參數決定程式品質。
  - **隊員**：可以手動指派每個人的工作，也可以讓隊員自動分配。
  - **訂單**：運送中的訂單和工作室日誌。
- **親手加工**（仿照真實機台的操作）：
  - **帶鋸機**：用捲尺量長度、劃線，把鋸片對到線的廢料側，開機後穩定送料。送太快會偏，甚至斷鋸條。
  - **台鑽**：移動工作台讓衝點對準雷射十字，選轉速，拖曳滑鼠下鑽並退屑。切屑卡住或下鑽太猛會斷鑽頭。
  - **車床**：零件是一條真的會被車掉的輪廓。開主軸、車端面、分刀車外徑、在指定長度切斷，用卡尺量。吃刀太深會震刀，沒開主軸就碰到會崩刀片。
  - **CNC**：
    - 放夾具，不能壓到刀具路徑。
    - 用尋邊器找板材角落，XY 歸零。
    - 用紙張法對刀，Z 歸零。
    - 算每刃進給量，按開始。之後機台會自己跑。
  - **3D 印表機**：切片（填充率、層高、外牆），四個角用紙張法調平熱床，開始列印後機台自己跑。
  - **工作台**：用銼刀去毛邊、去孔的毛邊；攻牙要繞圈並倒轉斷屑。
- **品質與批次：**
  - 尺寸誤差決定品質，太差就報廢，材料也沒了。
  - 同一道工序做完一件後，可以「照樣再做」剩下的件數：時間照算，品質會接近第一件。
- **組裝：**
  - 在推車上組裝，3D 機器人會隨進度長出來。
  - 機構子系統要逐顆鎖螺絲：按住讓扭力上升，在綠色區放開。
  - 電控要從 PDH 拉電源線到每個裝置（馬達接 40A、控制器接 15A），壓接端子，再串 CAN 匯流排。
  - 子系統品質由零件品質和組裝品質決定。沒組完的部分，隊員可以接手，你也可以下次繼續。
- **練習場：**
  - 底盤、驅動、電控和 bumper 都完成就能開到場上練習；沒做好的機構不能用。
  - 品質會影響速度和射球散佈。
  - 開車的時間會累積成操駕練習時數。
- **耗材：** 鑽頭、鋸條、端銑刀、車刀刀片、螺絲攻都會斷。用完了要去 MakerMart 補貨，不然那台機台的工作會停。
- **出發前（電腦「旅行」app）：**
  - 機器人怎麼過去：**陸運**（卡車，同一塊大陸才能走，提早 3 天寄）、**海運**（最便宜，提早一個月寄，回程也一樣久）、**行李箱／航空箱托運**（跟著飛機走，每箱 32 kg、超重超大件加錢，到了要重新組裝，比較容易在路上受損）。
  - 訂車票或機票（越早越便宜，太晚很貴）和飯店（三種等級，影響隊員體力恢復），決定帶幾個隊員。
  - 測試場地：向飯店租宴會廳／停車場，或寫信請當地隊伍借練習場（對方不一定答應），或不測試。
  - 到工作室門口的打包區裝箱：機器人、Driver Station 筆電、電池、充電器、工具箱、電鑽、scouting 平板、pit 佈置和備品，每樣都有重量。沒帶的東西到賽場就沒有（例如沒帶備品，修理就比較久、修不完全）。
  - 時間到了就出發，路程直接跳過；漏掉的票和飯店會用臨時價格補訂，沒打包會匆忙打包。
- **測試日：** 到了先拆箱（托運要重新組裝），在測試場地開到場上試車，看運送有沒有弄壞東西，同時累積練習；之後晚上 load-in。
- **賽事（標準三天賽程，3D 第一人稱）：**
  - 場館有場地、觀眾席（坐滿觀眾）、計分台、大螢幕、排隊區、紅藍入場口、Pit Admin，以及每一隊的 pit 攤位（真實隊號）。我們的攤位有機器人推車、電池充電車和 pit 白板。
  - 第 1 天：load-in、到 Pit Admin 申請安檢，檢查員會到 pit 檢查重量、尺寸、bumper、電控和能不能動。沒過要修好再申請；沒過安檢不能上資格賽。
  - 第 2、3 天：資格賽照時刻表進行，每場都有時間。輪到我們時，要把推車從 pit 推到排隊區，叫到時推到入場口，再選自己開或交給隊友；遲到算缺賽。派了「推車」的隊友就會自動幫你推。
  - 自己開的話是即時的比賽（Driver Station 視角）；交給隊友就由電腦依練習時數代打。
  - 每場之後機構會磨損、可能故障，電池也會沒電：回 pit 修理、保養、換電池（充電器一次充一顆）。分工成「Pit 維修」的隊友會自動處理。
  - 走到觀眾席就會即時轉播正在進行的比賽；其他時間別隊的比賽在背景模擬。
  - Scouting：派隊友 scouting（要帶平板），或自己在觀眾席看，就會累積各隊資料，選聯盟時看得到估計的進球和攀爬。Tab 打開平板：賽程、排名、scouting、隊員分工。
  - 第 3 天中午選聯盟（我們是隊長就自己選，被邀請可以接受或婉拒），接著雙敗淘汰賽。可以從出口回飯店（跳到隔天），或在淘汰賽時快轉到閉幕。
- **休士頓冠軍賽：** 場館照 FIRST 公開的 2026 喬治布朗會議中心（GRB）一樓平面圖還原：
  - Hall A（西）是 Archimedes、Daly、Curie、Galileo 的 pit，Hall E（東）是 Hopper、Milstein、Johnson、Newton 的 pit，pit 沿南北向的街道排列，外牆邊有練習場和測試區。
  - Hall B–D 由西到東排著 8 個分組場地，每個場地南北兩側都有看台，場地之間有簾幕；Hall C 後方是 Robot Service Center，Hall D 有 Ship Desk；pit 區和比賽區交界的隔牆旁是 Pit Admin。
  - 南側是大廳（FIRST Store、Registration），天花板大約三層樓高。
  - 週六淘汰賽時，聯盟的機器人移到北側看台後方的聯盟 pit（A1–N8）。
  - Einstein 那天用 Galileo 和 Johnson 兩個場地（MASS、ENERGY），中間是舞台，隊伍的推車在場地旁待命。
  - 場館很大，在休士頓時間放慢為 1 秒 = 20 秒，走到場地才不會吃掉整個賽程。各分組的隊伍排在正確的 pit 區塊裡，但每隊的攤位位置是推算的。
- **賽季：** 地區積分、地區冠軍賽與冠軍賽門檻、區域賽冠軍與積分池、休士頓分組和 Einstein 都照前面賽事模式的規則。比完回家，機器人依運送方式晚幾天（海運一個月）才回到工作室，可以繼續改機器準備下一場。最後一場結束會顯示整季成績。

### 賽事模式

選單「模式」選「賽事」，再選規模（24／32／40 隊）和等級（區域賽強弱混合；冠軍賽強隊多，五台真實機器人都會出現）。

「賽區」可以改選真實的 2026 賽事，用的是該賽事的真實隊伍名單：

- 14 個分區，每區提供地區冠軍賽、最強的幾場分區賽和最簡單的兩場。
- 7 個區域賽地區：美國西部、美國中部、美國東部、加拿大、拉丁美洲、土耳其、亞太。每區提供最強的幾場和最簡單的兩場。
- 休士頓冠軍賽的 8 個分組。

每場賽事旁邊會標難度（簡單／普通／困難／頂尖），依前 16 強隊伍的平均 EPA 和全部分區賽、區域賽比較。

如果你的隊號有參加那場賽事，就用自己的位置；沒有的話，會頂替其中一隊。沒有建模的隊伍會依 EPA 自動產生機器人。

- **資格賽：** 每隊 8–9 場，賽程會盡量平均休息、避免重複搭檔和對手。你只打自己的場次，其他場次在背景用 Web Worker 跑完整模擬（不畫畫面），你開車時也會繼續跑。自己的場次可以「上場」，也可以按「自動模擬」交給電腦代打。
- **排名：** 每場平均 RP，平手比平均分。排名表同時列出每台機器人自己的平均進球、爬升分和傳球，當作偵察數據。
- **選聯盟：** 前 8 名當隊長，第一輪 1→8、第二輪 8→1。電腦隊長照「進球 + 爬升分 + 傳球 × 0.5」挑人。你是隊長時自己邀請；被邀請時可以接受或拒絕，拒絕後就不會再被選，除非已經沒有其他隊可選。
- **淘汰賽：** FRC 的 8 聯盟雙敗淘汰（M1–M13），總決賽三戰兩勝。平手先比 TOWER 分，再比 AUTO 分，再來是種子較高的聯盟。
- **進度：** 存在瀏覽器（localStorage），關掉網頁再開會從同一個地方繼續；還沒跑完的背景場次會重新跑。

### 機器人工廠

選單機器人說明旁的「機器人工廠 →」。每一類選一種機構，左邊會即時顯示 3D 模型，右邊是算出來的性能：

| 類別 | 選項 | 影響 |
| --- | --- | --- |
| 底盤 | 標準方形、小型、寬型、長型、圓形 | 碰撞外形、intake 寬度、hopper 容量（依底面積）；小型轉向較快 |
| 驅動 | Swerve 均衡／高速／高扭力齒比、Mecanum | 最高速度、加速度、轉向速度 |
| Intake | 全寬滑軌、翻出式、固定內嵌式 | 吸球寬度、伸出距離、吸球速度 |
| Hopper | 中型、小型、可展開式、大型高 hopper | 容量、高度、能不能鑽 TRENCH |
| 射手 | 單砲塔、雙飛輪單砲塔、雙砲塔、固定式全寬滾筒、固定式單輪 | 射速、散布；固定式要轉車頭瞄準 |
| 攀爬 | L1、不爬、L2、L3 | 最高層數與爬升速度 |

每個機構都有重量，總重不能超過 115 lb（FRC 規則，不含 bumper 和電池），所以不能每樣都拿最好的。越輕加速越快（最多 +25%）。

#### 進階模式

工廠上方切到「進階」，改成用數值設定：

| 類別 | 可調 | 怎麼換算 |
| --- | --- | --- |
| 底盤 | 方形（長、寬）或圓形（直徑） | 周長不能超過 110 in；模組離中心越遠轉向越慢 |
| 驅動 | Swerve／Mecanum、Kraken X60／NEO Vortex／NEO、齒比 | 極速 = 馬達轉速 × 4 in 輪周長 ÷ 齒比；加速度隨齒比平方增加，上限 12.5 m/s²（輪子打滑），越重越慢 |
| Intake | 寬度、伸出距離（0–12 in）、滾輪轉速 | 寬度不能超過底盤；轉速決定吸球速度 |
| Hopper | 高度、可展開（多 8 in） | 容量依可用底面積 × 高度算；砲塔每座佔 4 顆、朝後的固定滾筒佔 8 in 深；高度 ≤ 22 in 才鑽得過 TRENCH（可展開的只看收起時），總高不能超過 30 in |
| Indexer | 輸送帶、旋轉盤、地板滾輪床、漏斗單列 | 決定總送球速度上限，也佔一點 hopper 空間 |
| 射手 | 砲塔（單／雙飛輪）或固定式滾筒（朝後／左／右）、1–3 座、每座的前後左右位置、滾筒寬度、飛輪轉速 | 射速：砲塔每座 7 或 10 顆/秒，滾筒每 in 寬約 0.7 顆/秒，總和受 indexer 限制。轉速決定出球速度和**射程**，轉速越高散布越大 |
| 攀爬 | 層數、爬升速度 | 越高、越快越重 |

每項都換算成重量並列出明細，超過 115 lb 或違反尺寸規則時不能存檔。

**射程：** 進階機器人的出球速度 = 轉速 × 0.0024 m/s，射擊時會在幾種弧線高度（可調 hood）中找出射得到的一種。全部都射不到時就不會出手，玩家畫面會提示「超出射程」，電腦會自己往 HUB 靠近。大約 2500 RPM 只能在區域邊緣射，3000 RPM 約 3.7 m，3800 RPM 以上整個己方區域都射得到。內建機器人和簡易模式的機器人沒有射程限制。

存好的機器人會出現在選單「我的機器人」分組，可以自己開，也可以指定給隊友或對手。拿去打賽事時，賽事會存一份當下的設定，之後再改機器人不會影響進行中的賽事。機器人存在瀏覽器（localStorage）。

### AUTO 自動程式

選單「AUTO 自動程式」旁的「編輯」。像 PathPlanner 一樣事先寫好 AUTO 20 秒要做的事，比賽時你的機器人會自己照著跑，搖桿要到 TELEOP 才接手（跟真的比賽一樣）。

- **起點：** 拖曳場上的機器人沿著起始線移動，再設定起點朝向。隊友會自動站到另外兩個起點。
- **步驟：** 依序執行。
  - 路徑：平滑曲線通過各點。可設定速度、要不要開 intake、要不要在己方區域邊走邊射、車頭方向（不轉、對準 HUB、朝行進方向）。
  - 射擊：停下來射到空為止，或時間到。
  - 原地吸球、等待。
  - 攀爬 L1。
- **編輯路徑：** 選取一個路徑步驟後點場地加點，拖曳可以移動，雙擊或右鍵刪除，點在路徑線上會在中間插入新點。
- **檢查：** 路徑撞到 HUB、機器人太高卻要鑽 TRENCH、整台車越過中線時會出現警告。
- **預覽：** 「預覽 AUTO」會在背景跑一次 AUTO 並在場地圖上重播，顯示軌跡、FUEL、得分，以及每個步驟幾秒開始。可以只放自己的機器人，也可以加入其他 5 台電腦機器人看會不會被擋。
- 程式存的是藍聯盟座標，紅聯盟會自動繞場地中心轉 180°。「左右翻轉」可以做出另一側的版本。
- 賽事中選「自動模擬」時，電腦代打你的機器人也會用這支 AUTO。
- 內建兩個範例：預載 → 中場掃球 → 回來射，以及預載 → DEPOT → L1。

## 電腦基準測試

打開 `bench/`（本機是 `http://localhost:8080/bench/`）按「開始」。它會把玩家位置換成不加成的愛因斯坦電腦，照記錄模式那 13 場的陣容（隊友 2 台 254、對手 3 台 254，皆傳奇／全力進攻）跑完整比賽，和玩家的平均進球比較。每場用固定 seed，同樣的設定會跑出同樣的結果；12 核心約 30 秒跑 64 場。

在 console 可以用 `bench.run(bench.benchJobs(16, { fireDepth: 1.5 }), 11)` 帶不同的 AI 參數（`AIFLAGS`）跑 A/B。

AI 的可調數字都在 `js/ai.js` 的 `AI_DEFAULTS`，每個聯盟可以各用一組（`settings.aiParams = { blue: {...} }`）。`bench.tune({ iters: 120 })` 會讓藍方用候選參數、紅方用預設值，自動爬山搜尋；跑完一定要用新 seed 驗證（`bench.evalJobs(params, 50000, 16, 64)` 共 128 場）。第一次搜尋 24 個參數、120 次迭代，驗證結果和預設值沒有差別（−7 ± 7 顆）。（當時「隨機陣容」的產生器有 bug，實際全是 254，所以這個結論只適用於全 254 的場面。）

撿球路線規劃（`sweepPlan`）：愛因斯坦以上的方形轉塔車，從目前位置往 16 個方向、3 種長度（再加一條穿過最密集區域的線）各估一條直線衝刺路線：沿路 intake 會掃到幾顆球 ÷ 轉向和開過去的時間（加上離家多遠），挑最好的一條全速開過去，比目前這條好 30% 以上才換。基準測試裡 4414 從 434 升到 540 顆、1690 從 434 升到 560 顆；64 場隨機陣容對打，藍方多 30 ± 12 顆、紅方不變。4946（圓形底盤）會把球往兩側推開，估算時只算 60% 的 intake 寬度，這樣它在基準裡從 431 升到 457 顆。254 套用後反而變差（約 −10%），所以固定射手不套用。

評估改動要看兩種結果：基準（全場同一套 AI）和對打（藍方新、紅方舊）。例如 254 不跑 BUMP 循環，在基準裡多 22 顆，但對打時藍方少 30 ± 9 顆。全場一起改變了比賽的動態，不代表它比較強，所以保留 BUMP 循環。目前基準（全場都用新 AI，所以對手也變強了）：254 70%、4414 78%、1690 81%、4946 87%，平均 79%。

## 電腦 AI 與戰術

每個聯盟有一個「團隊大腦」，每 0.25 秒依 HUB 輪替重新分配角色（機器人頭上會顯示，可在選單關閉）：

| 角色 | 做什麼 |
| --- | --- |
| 得分 | 己方 HUB 啟用時在 Alliance Zone 內連續射擊；砲塔機邊射邊撿區內的球、被頂時橫移閃避 |
| 囤球 | 己方 HUB 停用時把 hopper 裝滿；愛因斯坦級裝滿後會繼續吸球並把多的傳回己方區域，Neutral Zone 見底時改去 OUTPOST 拿 Human Player 的球 |
| 就位 | 啟用前依移動時間提早回到區域邊緣，按實際飛行時間提前開火，球落下時剛好啟用 |
| 供球 | 在 Neutral Zone 收球並吊傳進己方區域給得分手 |
| 防守 | 守住對手回家要走的 BUMP／TRENCH 通道，近距離卡位（不進對手 Alliance Zone）；沒目標時就清掉中場的球 |
| 反防守 | 把頂住隊友的防守機推開 |
| 搶球 | 進對手區域把他們囤的球吸走再傳回自己區域（斷糧） |
| 路線 | 過 HUB 線時挑最近的 BUMP 或 TRENCH，避開有對手擋著的那條；困難以上、鑽得過 TRENCH 的車會偏好 TRENCH（走 BUMP 視為多繞 1.5 公尺）。全部都走 TRENCH 反而會擠在一起，1.5 公尺測起來最好（進球多約 7–8%） |
| 攀爬 | 困難以上每台在該出發的時間點比較：爬上去的分數（轉塔車路上還能把球射完）vs. 留下來還能射進的球（車上的球 + 依自己整場進球速度再跑一輪），划算才去爬 |

AUTO：先射完預載，到中場掃球，最遠可越過中線約 1.5 公尺（Team Update 22 規定不能完全越過中線，但實際比賽中不是太刻意的話很少被判，頂尖隊伍常這樣做；越線後 AUTO 進球多約 8%，也會在中線附近互撞），最弱的一台拿 DEPOT 後爬 L1。

收球（困難以上）：把場地切成 0.6 m 格子統計地上的球，選「球數 ÷ 來回時間」最高的一塊，朝球堆重心直線衝過去；貼牆的球會先擺正車頭再推進去。愛因斯坦級在 HUB 射空後會翻過 BUMP 守在自家 HUB 出球口接回剛射進的球。

固定式射手（困難以上）預設跑「角落循環」，是照玩家記錄裡的 254 開法做的：停在己方區域深處 2.4 公尺、偏離中線 2.9 公尺的位置站定射擊（那裡沒人經過，不會被撞歪），走 TRENCH 出門，在己方這半邊的中場掃球，裝到 70% 或 Shift 快結束時回家。好幾台時各佔一個角落。對打測試裡贏過舊的 BUMP 循環（分差 +32 ± 9 顆，全 254 陣容 +51 ± 14）。舊的 BUMP 循環仍保留（`cornerLoop: false`）：車頭始終朝自家牆，停在 BUMP 後方、進入區域約 1.2 公尺的位置用車尾滾筒射 HUB（停在 BUMP 頂會擋在大家進出的路口，常被撞歪；往後移之後三台 254 的總進球多約 7%）；射空後倒退下 BUMP 到 HUB 中場側，掃回自己射進後吐出來、被撞回 HUB 附近的球，再開回 BUMP 射擊。砲塔機不用這套。同聯盟有好幾台在跑這套時，由團隊分配射擊點：兩台各佔一條 BUMP，第三台去遠離 OUTPOST 那側的 TRENCH 出口（鑽不過 TRENCH 的話就兩台擠一條 BUMP），HUB 下的球也依射擊點分區撿，不會三台搶同一塊。

傳奇難度：戰術同愛因斯坦，但機器人的速度、加速、吸球、射速比規格快 50%、精度更高——給已經能贏愛因斯坦的玩家用。

戰術：均衡（依情況）、全力進攻、供球、防守、斷糧；對手可設「隨機」。被對手碰撞時射擊精度下降，固定式射手無法開火，所以防守真的有用；困難以上的機器人也會避開被佔住的通道。

參考：Chief Delphi 上的 [Inactive Period Strategy](https://www.chiefdelphi.com/t/whats-the-best-inactive-period-strategy/512049)、[Ithaca 防守](https://www.chiefdelphi.com/t/rebuilt-2026-defense-the-ithaca-strategy/518957)、[賽季回顧](https://www.chiefdelphi.com/t/post-season-reflect-how-was-rebuilt/519847?page=10) 與 [Team Update 22](https://firstfrc.blob.core.windows.net/frc2026/Manual/TeamUpdates/REBUILT_TeamUpdate22.pdf)。
